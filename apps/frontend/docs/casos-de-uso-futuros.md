# Casos de uso futuros

Ideias levantadas a partir do uso real do laboratório. Nenhuma foi decidida ainda; situação de todas: **falta**.

| # | Perfil | Caso de uso | Depende de |
| --- | --- | --- | --- |
| 1 | Analista | Editar o cadastro da amostra depois de criada (nome, CPF, propriedade, datas) | produto e backend (endpoint de edição); front pode ser preparado |
| 2 | Analista | Baixar ou imprimir o PDF do laudo pelo painel | backend (PDF real); front reaproveita o download do cliente |
| 3 | Analista | Ver um laudo homologado completo pelo histórico | só front (usa a visualização de homologação) |
| 4 | Analista | Reaproveitar a curva de calibração do dia em várias amostras | produto; pode ser feito só no front |
| 5 | Analista | Avisar o cliente quando o laudo ficar pronto (e-mail/telefone do cadastro) | produto e backend |
| 6 | Cliente | Recuperar o protocolo esquecido | produto e backend (com cuidado de segurança) |
| 7 | Cliente | Ver todos os laudos do mesmo CPF | produto e backend |
| 8 | Administração | Gerenciar quem pode entrar como analista | produto e backend |
| 9 | Administração | Histórico de alterações de cada análise (auditoria) | backend |
| 10 | Administração | Relatórios (amostras por mês, atrasos) | produto e backend |
